# The board: cards, folders, piles, the right-click menu

Everything the board draws and every gesture on it.

- Pan, zoom (buttons, wheel, fit), and whether cards stay where they were put.
- Drag cards: onto empty space, onto each other, onto a folder, off the edge.
  Does the drop land where it was aimed, and does it snap to the grid gutter?
- Select several cards and use what the selection offers: pile, spread, arrange.
- Right-click every kind of card, the empty board, and a selection. Does each
  menu item do what it says?
- Open a folder, go back up; open a note and edit it in place.
- Does what the board shows match what is in `demo/.nib/` on disk after each
  of the above?
