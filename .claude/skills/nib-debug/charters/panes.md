# Panes and docks: opening, splitting, resizing, closing

The panes around the board and the docks they sit in.

- Open every pane type (`debug panes`), through the UI where it offers a way
  and through `debug pane` where it does not. Does each render something useful
  for the demo project, or say why it cannot?
- Open several into one dock; drag panes between edges; resize a dock by its
  divider. Does the board keep a usable size?
- Close panes by their close button and with the keyboard; does focus go
  somewhere sensible?
- The project explorer, git and file panes against the demo project's files.
